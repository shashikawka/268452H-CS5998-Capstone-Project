# In26-S3-CS5998-Capstone-Project

# Anomaly Detection for Predictive Maintenance of Railway Air Production Units Using Multivariate Sensor Data

## Overview

This project investigates anomaly detection in multivariate time-series sensor data from a railway Air Production Unit (APU) to support predictive maintenance.

The project uses the MetroPT-3 dataset, which contains sensor measurements collected from the Air Production Unit of a metro train. The project will 
investigate methods for identifying abnormal operating behaviour and evaluate detected anomalies using documented failure periods associated with the dataset.

## Project Objectives

- Explore and preprocess multivariate railway sensor data.
- Analyse normal operating behaviour and documented failure periods.
- Develop a baseline anomaly detection approach.
- Develop and evaluate an improved anomaly detection approach.
- Compare the approaches using appropriate evaluation measures.
- Provide a lightweight visualization interface for sensor and anomaly analysis.

## Dataset

The project uses the MetroPT-3 dataset.

The dataset contains multivariate time-series measurements from a railway Air Production Unit, including pressure, temperature, motor current and
operational state variables.The dataset is not stored directly in this repository.
